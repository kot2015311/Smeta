# Расчёт сметы — сайт агентства мероприятий

Сайт с онлайн-калькулятором сметы. Посетитель выбирает формат, число гостей, площадку, питание и услуги — и сразу видит вилку цены, разбивку по статьям и схему зала. Заявку на звонок можно отправить вместе с расчётом, чтобы менеджер не собирал параметры заново.

Обычный статический сайт: HTML, CSS и JavaScript без библиотек и сборки. Работает на GitHub Pages и открывается двойным щелчком по `index.html`.

## Что умеет

- **Калькулятор.** 5 форматов, от 10 до 500 гостей, длительность, дата, уровень организации, площадка, питание и 16 услуг. Рядом с каждой услугой видно, сколько она добавит при текущих параметрах.
- **Живая смета.** Вилка цены, сумма на гостя, НДС 22% отдельной строкой, каждая статья с пояснением, работа агентства.
- **Схема зала.** Рассадка меняется от формата и числа гостей: ряды для конференции, круглые столы для банкета, коктейльные столы для фуршета, команды для тимбилдинга. Услуги добавляют на схему сцену, экран, фотозону, диджея и стойку регистрации. Под схемой — нужная площадь зала.
- **Сезон и срочность.** Декабрь +20%, январь −10%, меньше двух недель до даты — +15%.
- **Бюджет и экономия.** Можно указать бюджет: сайт подскажет, что изменить и сколько это сэкономит, и применит изменение одной кнопкой.
- **Поделиться расчётом.** Ссылка на тот же расчёт, PDF и текст для мессенджера. Расчёт сохраняется в браузере.
- **Остальные разделы.** Примеры смет, сравнение уровней, этапы работы, вопросы и ответы.
- **Заявка на звонок.** Маска телефона, проверка полей, отдельное согласие на обработку персональных данных, защита от ботов, статус «на связи / не на связи» по московскому времени.
- **Качество.** Адаптивная вёрстка, работа с клавиатуры, контраст текста, подписи для экранных дикторов, учёт настройки «уменьшить движение», шрифты внутри проекта — без запросов к Google.

## Запуск у себя

Откройте `index.html` в браузере. Или запустите локальный сервер — так сайт работает ровно как на GitHub Pages:

```bash
python -m http.server 8000
# открыть http://localhost:8000
```

## Как выложить на GitHub Pages

1. Создайте на GitHub публичный репозиторий, например `smeta`.
2. Загрузите файлы — один из двух способов:
   - **Через браузер:** Add file → Upload files → перетащите содержимое папки проекта (не саму папку) → Commit changes. Скрытые файлы и папки (`.github`, `.nojekyll`, `.gitignore`) так могут не загрузиться — сайт работает и без них.
   - **Через git:**
     ```bash
     git init
     git add .
     git commit -m "Сайт с калькулятором сметы"
     git branch -M main
     git remote add origin https://github.com/USERNAME/smeta.git
     git push -u origin main
     ```
3. В репозитории: Settings → Pages → Build and deployment → Source: Deploy from a branch, Branch: `main`, папка `/ (root)` → Save.
4. Через минуту-две сайт откроется по адресу `https://USERNAME.github.io/smeta/`.
5. Впишите этот адрес в `assets/js/config.js` → `siteUrl`, а в `index.html` в теге `og:image` замените `assets/img/og-cover.png` на полный адрес картинки — тогда превью ссылки появится в Telegram и VK.

## Что заменить перед запуском

| Что | Где |
|---|---|
| Телефон, Telegram, почта | `assets/js/config.js` → `contacts` |
| Часы работы | `assets/js/config.js` → `schedule` |
| Название «Расчёт сметы» | `index.html` (заголовок, логотип, подвал), `config.js` → `brand` |
| Цены и услуги | `assets/js/config.js` |
| Реквизиты оператора данных | `privacy.html`, `consent.html` — это шаблоны, проверьте их с юристом |

Пока контакт не заполнен, на сайте видна заглушка вида `[+7 (000) 000-00-00]`, и ссылка на неё не создаётся.

## Как устроены цены

Все цены лежат в `assets/js/config.js`, в рублях без НДС. Массив из трёх чисел — цены для уровней «Стандарт», «Комфорт» и «Премиум»:

```js
{ id: 'host', group: 'program', title: 'Ведущий', desc: 'Ведёт программу и держит тайминг',
  unit: 'perHour', minHours: 2, price: [8000, 15000, 30000], note: '{h} {h|час|часа|часов} работы' }
```

Поле `unit` задаёт формулу: `fixed` — фиксированная сумма, `perGuest` — за гостя, `perHour` — за час, `perStaff` — за сотрудника в день, `perVehicle` — за автобус и другие. Полный список с пояснениями — в начале файла. Чтобы добавить услугу, допишите такой же объект в `services`: она сама появится в калькуляторе, смете, PDF и заявке.

Как складывается итог:

1. Программа формата, площадка, питание и выбранные услуги.
2. Сезон и срочность — процент от этих позиций (подарки не дорожают в сезон).
3. Работа агентства — 10/12/15% в зависимости от уровня, но не меньше 25 000 ₽.
4. Вилка — от −10% до +15% вокруг итога. НДС показывается отдельной строкой.

Стартовые цены собраны из таблицы конкурентов и открытых данных о рынке 2025–2026 годов (кейтеринг в Москве — от 2 000 ₽ за гостя, ведущий — 10–30 тысяч ₽ в час, полноценный корпоратив — от 10–15 тысяч ₽ на гостя). Замените их на цены своих подрядчиков. После правок запустите тесты — они проверят, что в настройках нет ошибок.

## Куда приходят заявки

**Письмо (по умолчанию).** Если в `config.js` заполнена `contacts.email`, а `lead.endpoint` пустой, кнопка «Заказать звонок» откроет почтовую программу посетителя с готовым письмом.

**Telegram через сервер (папка `server/`).** Токен бота нельзя хранить в коде сайта — его увидит любой посетитель. Поэтому заявку принимает маленький сервер на Flask и пересылает в чат менеджеров:

1. Создайте бота в [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Добавьте бота в чат или группу менеджеров и напишите там любое сообщение. Откройте `https://api.telegram.org/bot<токен>/getUpdates` и найдите `"chat":{"id": ...}` — это `TELEGRAM_CHAT_ID`.
3. Скопируйте `server/.env.example` в `server/.env` и заполните. Файл `.env` в репозиторий не загружается — он в `.gitignore`.
4. Запустите сервер на любом хостинге с Python и HTTPS:
   ```bash
   cd server
   pip install -r requirements.txt
   gunicorn -w 2 -b 0.0.0.0:8000 app:app
   ```
5. Впишите адрес в `assets/js/config.js`: `lead: { endpoint: 'https://ваш-сервер/api/lead' }`.

Сервер принимает заявки только с адресов из `ALLOWED_ORIGINS`, ограничивает число заявок с одного адреса, пропускает ботов, заполнивших поле-ловушку, экранирует текст и не принимает заявку без согласия на обработку данных.

Если заявки хранятся только в Telegram, уточните у юриста требования закона № 152-ФЗ к локализации данных: возможно, заявку нужно сначала сохранять на сервере в России.

## Тесты

```bash
node --test tests/estimate.test.js        # расчёт, схема зала, настройки цен — 17 тестов
```

## Структура

Код прокомментирован на русском. Разбираться удобнее в таком порядке: `config.js` (цены и настройки) → `estimate.js` (формулы) → `app.js` (как всё связано со страницей) → `server/app.py` (приём заявок).

```
index.html            главная страница
.nojekyll             GitHub Pages отдаёт файлы как есть, без обработки Jekyll
privacy.html          политика обработки персональных данных (шаблон)
consent.html          согласие на обработку персональных данных (шаблон)
404.html              страница «не найдено» для GitHub Pages
assets/
  css/styles.css      все стили; цвета и шрифты — в начале файла
  js/config.js        цены, услуги, контакты, график, адрес приёма заявок
  js/estimate.js      формулы расчёта (без работы со страницей)
  js/plan.js          схема зала в SVG
  js/app.js           интерфейс: калькулятор, смета, PDF, ссылка, заявка
  fonts/              шрифты Tektur и Inter с лицензиями
  img/                иконка сайта и картинка для превью ссылки
  icons-LICENSE.txt   лицензия иконок Lucide
server/               приём заявок → Telegram (Flask)
tests/                тесты расчёта
```

## Что можно сделать дальше

- Подключить Яндекс Метрику с целью «Отправил смету менеджеру» — и описать это в политике обработки данных.
- Хранить заявки в базе (например, SQLite на сервере) и дублировать их на почту.
- Вынести цены в Google Таблицу, чтобы менеджеры меняли их без программиста.
- Подключить свой домен: Settings → Pages → Custom domain.
